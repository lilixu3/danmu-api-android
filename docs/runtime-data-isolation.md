# 运行实例与本地弹幕库隔离

## 根因和边界

上传请求原本发送到正在运行的核心，本地列表却优先直接读取普通模式的 `.cache/local-danmu`。Root 运行目录、普通目录、下载记录的全局“已导入”标志因此可能相互矛盾。只给列表增加 Root 分支无法处理切换模式、目录、核心和服务重启后的旧结果。

此次按六个层面修复，保留现有未提交功能，不修改应用版本：

1. **统一目标**：`RuntimeDataAccess` 每次操作捕获模式、目录、核心、端口与鉴权信息；联网前以 `/__health` 校验实际目录、实际加载的核心及应用实例身份。没有完成校验就不执行操作，不自动改投另一个实例。
2. **分离身份**：会话标识覆盖启动、重载、配置和核心修订；Android 的 Node 核心将本地弹幕存放在文件目录，持久库标识只表示实际目录。Upstash / Local Redis 的查询缓存配置不改变本地弹幕库归属，错误的 Upstash 地址也不能让宿主身份检查抛错。重启和切换共用目录的核心不应把原有文件伪装成新库。凭据不直接进入持久键或日志。
3. **统一访问**：本地弹幕列表、详情、预览、上传、删除、改元数据全部走当前核心 API。清理协议由实际运行目录中的核心提供，不再读取普通目录镜像。诊断和备份使用显式目标的 `RuntimeStorageGateway`，Root 读取失败明确报错，不回退普通目录。
4. **防止串库和旧结果覆盖**：操作门串行化上传及来源登记、服务启停和热更新；请求携带会话标识，Node 在分发及读取请求体后再次核验，旧实例请求返回 409。切换后清空旧界面状态；批量任务固定目标，不跨实例继续。写请求禁用连接失败自动重试。
5. **持久数据按库隔离**：来源表以库标识和资源键联合索引；下载记录新增 `localImports`。界面的“当前库已导入”只由成功取得的当前列表确认，优先验证已关联的真实资源键，再按元数据匹配；手动订正标题/年份不会丢掉导入标记，编辑资源时同步迁移关联。旧全局时间戳仅代表历史导入。遗留来源不猜测归属、不删除文件；当前列表失败不能当作空列表清除关联。
6. **约束后续开发**：不带模式参数的 `projectDir(context)` 标为编译错误；Node 架构测试约束已迁移的数据消费者；添加身份、串行操作、持久关联、类型判断及真实宿主会话拦截测试。

普通模式的引导、应用日志、Root 首次安装的暂存目录仍可显式使用 `normalProjectDir`。这些不是当前核心数据源，不应机械替换成 Root 目录。

## 导入类型

- 新下载任务和记录保留搜索结果中明确的电影/电视剧类型，避免通用 `_E01` 文件名覆盖电影信息。
- 手动导入使用实际相对目录、文件名及匹配的下载记录；电影目录/标记、季集信息参与判断。
- 没有可靠类型依据时显示“待确认”，不默认电视剧，也不根据单个文件就猜电影；未识别年份不补当前年份。
- 提供“自动 / 电影 / 电视剧”批量设置，电影不携带集数；自动恢复最初识别结果。确认后的类型写入对应下载记录。
- 普通搜索下载和链接下载成功后都可触发自动导入，包括链接使用的负数集号；目录同步记录使用集号 0，仍不会自动导入。缺少必填元数据时提示订正，不静默跳过链接下载。

## 兼容性与限制

- 同版本覆盖安装后，需要重启核心服务，才能启用新的宿主健康检查与会话协议；旧宿主会明确要求重启，而不是无校验继续写入。
- 不迁移或合并 Root 与普通模式的弹幕文件。相同资源键可以分别存在，两边独立维护。
- 旧核心的列表接口可能较慢；本次以核心 API 为权威，移除 Android 侧读取未验证缓存目录的捷径。若以后增加轻量元数据接口，应在运行核心一侧实现，校验同一会话及实际存储后使用，不能恢复普通目录回退。
- 已知库标识适用于本项目 Node 核心的本地弹幕文件存储。自定义核心若更改本地弹幕存储后端、命名空间或清理协议，需扩展宿主适配及测试，不能仅凭 Redis 环境变量猜测后端或授权破坏性操作。
- 主机自动测试不是手机端 Root/SAF 实测。建议安装后分别验证两种模式导入、同名资源隔离、切换后的列表和清理、电影批量识别。

## 回归入口

```sh
node --test node-tests/runtime-data-context.test.cjs
./gradlew :app:testDebugUnitTest :app:assembleRelease --console=plain
```

Release 的兼容性检查需要与内嵌运行时相同主版本的 Node。当前为 Node 26.12.1；可通过 `DANMU_TARGET_NODE` 或 `-PtargetNodeExecutable=绝对路径` 指定，不应关闭检查来绕过版本不匹配。

Termux 上长时间复用 2 GB Gradle 进程，可能在三个 ABI 打包时出现 Java heap space。可以为本次命令使用 `--no-daemon --max-workers=1 '-Dorg.gradle.jvmargs=-Xmx3g -Dfile.encoding=UTF-8'`，不必修改项目的全局构建配置。

新测试覆盖真实 direct / Worker 宿主：旧会话写请求不进入核心、正确会话可以写入、原 TOKEN 鉴权保持生效、磁盘核心变化但未加载时拒绝写入；同时验证实际运行目录、库标识和会话标识的关系。
