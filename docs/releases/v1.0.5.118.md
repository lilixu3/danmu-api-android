# v1.0.5.118

## 更新日志

- 修复使用含 `+`、`@`、`:`、`=`、`%` 等特殊字符的 `ADMIN_TOKEN` 打开管理网页后，保存环境变量误报“需要管理员权限”的问题（#49）。App 管理接口兼容原始令牌和 URL 编码后的令牌，保留完整令牌匹配与网页来源校验；无需修改核心代码。
- 默认环境配置改用核心仓库的完整示例模板，解决 APK 无法可靠打包隐藏的 `.env` 文件，导致首次启动缺少默认配置的问题。首次运行自动生成工作目录的 `config/.env`，默认令牌读取同步使用新模板。
- 升级时仅补充模板中新增且本地缺失的配置，保留用户已有值、空值、自定义项和显式注释掉的配置；同一模板只合并一次，避免反复补回用户主动删除的项目，并保留 Windows 换行格式。
- 同步较新的核心默认配置与说明，补充收藏和本地弹幕权限、来源并发、标题清理和映射等配置项。全新配置默认搜索顺序调整为 `douban,360,renren,hanjutv`，搜索和弹幕缓存改为 3 分钟，VOD 上游默认为空；已有配置值不被覆盖，已有 VOD 上游如需停用请手动清空。
- 修复服务运行配置缺少 `TOKEN` 或本机令牌路径不匹配时，网络页健康检查、来源列表和来源探测误报服务未连接的问题；App 在遇到 401、403 或 404 后尝试无令牌的本机回环路径。
- 内嵌运行时升级为 **Node.js 27.0.0-alpha.0.0.0 App lite + OpenSSL 4.1.0**，保留增强直连的 ECH、HTTP/2 和 HTTP/3 能力。同步三个架构的原生库校验值、头文件、JNI/C++ 构建记录、许可证和来源追溯信息；兼容已验证的签名 JavaScript 依赖包，继续校验签名、哈希和包内容。此处为 Node alpha 运行时，并非 Node 27 正式版。
- 构建签名支持项目独立的 `.signing` 配置目录，并将该目录加入 Git 忽略；打包时缺少项目签名会明确报错，避免误用其他证书。
- 补充特殊字符管理员令牌、编码边界、direct/Worker 配置读写、默认配置合并和本机访问路径回退的回归测试，同步架构、代理探测和运行时隔离文档。

## 升级后测试

安装后在首页停止并重新启动服务，以加载新的运行时和管理脚本；管理员网页请重新打开或刷新后测试保存。

安装包分别提供 arm64-v8a、armeabi-v7a 和 x86_64。Android 最低版本仍为 7.0（API 24）。
