# v1.0.5.119

## 更新日志

### 请求记录

- 重新设计请求卡片。接口、时间、HTTP 状态、客户端和耗时分开显示，卡片上可以展开原始请求参数、复制接口地址或打开「处理链路」。按文件名匹配的请求会突出显示文件名，默认展开参数。
- 对于支持请求追踪的核心，App 在直连和 Worker 两种运行模式下都会关联核心返回的 `requestId`。打开详情即可查看准备和处理耗时、最慢步骤、候选数量变化与结果诊断，也能展开每一步的输入、输出和过滤原因。在「配置覆盖」中可以筛选本次实际读取或命中的配置。旧核心和历史记录仍可查看已有信息。
- 修正请求统计。「今日」使用核心返回的全天请求次数，即使只保留了最近 200 条记录也能显示完整计数。P95 只使用有耗时的样本，实测 0 毫秒会保留，没有样本时显示「—」。
- 下载页刷新剧集时，源端搜索和分集快照现在归入同一次请求。App 和核心网页都能看到完整耗时、取得的快照数量，以及刷新失败后回退到已有结果的原因。

### 配置管理

- 新增「按剧名指定匹配来源」（`TITLE_PLATFORM_MAP`）快捷编辑。可以从当前核心支持的平台和已配置的合并来源组中选择，也可以按行或分号批量粘贴。同一剧名以最后一项为准，已有的自定义来源仍可编辑。
- 普通界面和 TV 兼容界面的映射规则统一为一行「原值 → 映射值」。自动匹配的季集映射支持来源第 0 季，例如 `灵笼 S00E01 → 灵笼 S01E07`。输入文件名可预览结果，目标季和集号须从 1 开始。
- 远程剧名映射表和季集映射表都可以在配置页点「立即更新」。App 会核对运行中核心已加载的地址，再以管理员身份刷新，显示更新时间、规则条数或失败原因。
- 编辑来源组合、自定义合并或阻断规则、弹幕时间偏移、单个或批量颜色时，填好当前条目即可直接保存。已确认的条目不会重复追加，批量颜色会先校验，并保留已保存的十进制色值。空配置恢复显示「未设置」，敏感配置有值时仍以圆点遮盖。

### 推送、下载与接口调试

- 推送和下载选集优先使用标题中唯一的集号。例如源站删去第 2 集后，「第 3 集」仍可按 3 定位。标题没有集号或同号出现多次时沿用核心序号。下载刷新和失败任务重试也会核对旧记录的标题，减少漏补或重复下载。
- 接口调试页的「搜索剧集」支持可选的 `episode` 参数。输入集号可查指定集，输入 `movie` 可筛选电影，留空可查看全部剧集。

### 内嵌运行时

- Node.js App lite 从 `27.0.0-alpha.0.0.0` 升至 `27.0.0-alpha.0.1.1`，使用 OpenSSL 4.1.0 和 nghttp3 1.19.0。三个架构的运行时均已同步，更新了原生库哈希、构建来源记录及运行时文档。
- 改进原生库的页对齐检查。构建会检查 GNU RELRO 按页取整后是否覆盖额外的可写数据，兼容新版链接器生成的合法填充。

## 升级说明

安装后请在首页停止并重新启动服务，以加载新的运行时和管理脚本。请求处理详情需要支持追踪的核心，更新核心后新产生的请求即可使用。
